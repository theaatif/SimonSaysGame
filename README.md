# Simon Says Game

A simple version of the classic Simon Says memory game built using HTML, CSS, and JavaScript. In this game, players need to repeat the sequence of flashing buttons correctly in order to progress to the next level. Each level adds one more button to the sequence.

## Game Features

- Starts with a random button sequence.
- User clicks buttons in the same order as the sequence.
- Each correct repetition adds a new button to the sequence.
- The game ends when the user makes a mistake, and the final score (level) is displayed.

## How to Play

1. Press any key to start the game.
2. Watch the sequence of flashing buttons.
3. Click the buttons in the exact order they flashed.
4. Each time you repeat the sequence correctly, a new button is added.
5. If you make a mistake, the game ends, and your final score is shown.
